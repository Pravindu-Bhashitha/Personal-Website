# Pravindu Bhashitha — Portfolio

Personal portfolio built with React + Vite. Live at https://pravindu-bhashitha.github.io

## Editing

All content (profile, experience, projects, skills, education) lives in `src/data.js`.
The photo and CV are in `src/assets/`.

## Commands

```bash
npm install      # first time only
npm run dev      # local dev server at http://localhost:5173
npm run deploy   # build and publish to GitHub Pages
```
